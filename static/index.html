1분 만에 FarmFinder 구글 시트 자동 기록 연결하는 법 보기
  1. 상단 [FarmFinder 시트 열기] 클릭 → 메뉴 확장 프로그램 > Apps Script 클릭
  2. 아래 코드를 붙여넣고 우측 상단 배포 > 새 배포 > 유형: 웹 앱 선택 (액세스 권한: 모든 사용자)
  3. 생성된 웹 앱 URL을 위 입력칸에 붙여넣고 저장하면 즉시 시트에 자동 기록됩니다.
